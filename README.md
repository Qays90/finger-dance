Finger Dance

Finger Dance is an interactive 3D hand animation project built with Python and Panda3D. It explores independent finger motion through dance, piano, wave, and gesture modes.

The movement design is inspired by circles and geometric links. A joint-spacing guard limits how closely selected joint points on neighboring fingers can approach each other. It is not a full mesh-collision or physics simulation.

Download and run on Windows

1. Download finger-dance-windows.zip.
2. Right-click the downloaded ZIP and select Extract All.
3. Open the extracted finger-dance folder.
4. Double-click Start.cmd.

The package includes a 64-bit Windows Python runtime, the required libraries, and the hand model. You do not need to install Python or run pip commands separately
